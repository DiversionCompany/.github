## What is Diversion?

Diversion is a version control system built for teams that outgrow Git and want to avoid the operational cost of Perforce. It handles massive repositories and large binary assets, syncs in real time, and runs in the cloud — no servers to host or scale yourself. It's a good fit for game studios, virtual production, AR/VR, and any team working with mixed code and binary content.

A few concrete numbers from real workloads:

- Clone **5M files in under 5 minutes**
- Commit **400K files in under 30 seconds**
- **100+ commits/min** with no impact on users

## Install & quickstart

**macOS / Linux**

```sh
curl -fsSL https://get.diversion.dev/unix | sh
```

**Windows** — download the installer from [`get.diversion.dev/win`](https://get.diversion.dev/win).

Then:

```sh
dv login
dv clone <repo>
dv status
dv commit -a -m "your message"
```

Full walkthrough: **[docs.diversion.dev/quickstart](https://docs.diversion.dev/quickstart)**
